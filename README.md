# Node.js Server з PUG та EJS

## Опис
Цей сервер віддає сторінки за двома групами маршрутів:

- `/users` та `/users/:userId` — сторінки користувачів, рендеряться за допомогою PUG.
- `/articles` та `/articles/:articleId` — сторінки статей, рендеряться за допомогою EJS.

Для покращення вигляду використані прості CSS стилі.

## Встановлення

```bash
git clone <посилання_на_репозиторій>
cd <папка_репозиторію>
npm install
npm start
```

## Маршрути

- `GET /users` — список користувачів
- `GET /users/:userId` — деталі користувача
- `GET /articles` — список статей
- `GET /articles/:articleId` — деталі статті

## Технології
- Express.js
- PUG (для користувачів)
- EJS (для статей)
- CSS для стилів
